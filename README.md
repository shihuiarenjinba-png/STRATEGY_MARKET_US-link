## About the game

Manage a fictional U.S.-themed economy with companies, competition, prices, financial decisions, and changing market conditions. Historical periods are **stylized fictional game scenarios**, not reliable recreations of real markets, financial forecasts, or investment advice. The core game does not require an external AI service or account.
